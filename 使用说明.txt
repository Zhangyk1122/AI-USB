AI-USB-Demo 使用说明
====================

这是什么
--------
便携版 DeepSeek Harness：只有这一个 Agent，只有 Windows x64 版本。
把整个文件夹复制到 U 盘，插到 Windows 10/11 x64 电脑即可使用；
目标电脑不需要安装 Node、npm 或任何软件。


启动（三步）
------------
1. 把【整个】AI-USB-Demo 文件夹复制到 U 盘（不要只复制 .bat 文件）。
2. 插到 Windows 电脑，打开 U 盘里的 AI-USB-Demo 文件夹。
3. 双击 dsh.bat。黑窗口打印地址后，浏览器会自动打开 Harness 界面。
   关掉这个黑窗口就等于停止服务。

   命令行方式（先把当前目录切到本文件夹）：
     cmd          dsh
     PowerShell   .\dsh
     带参数       dsh web --port 8080
     （web 参数写在 web 后面；写成 dsh --port 8080 会报 --profile 缺失）
                  dsh headless "任务内容"
                  dsh --version

   Windows-Start.bat 是 dsh.bat 的别名，双击效果相同。


第一次使用
----------
启动不需要提前填任何 Key。
打开界面后，在“模型 / 供应商”设置里添加自己的 API Key 即可；
配置保存在 U 盘 data\harness 目录，换电脑后继续有效。


常见问题
--------
1) 双击没反应或被杀毒软件拦截：
   右键 dsh.bat -> 属性 -> 勾选“解除锁定”后再双击；杀软提示时选择允许/信任。
2) 提示 supports Windows x64 only：
   这台电脑不是 x64（例如 ARM 版 Windows），无法使用。
3) U 盘格式：
   建议 exFAT 或 NTFS。FAT32 会有单文件 4GB 限制和长路径问题。
4) 环境变量是自动设置的吗？
   是，但只对当前这个黑窗口生效：DSH_HOME、缓存目录、PATH 等由启动器临时设置，
   不会修改系统环境变量，也不会安装全局命令。
5) 想启用随包插件？
   把 plugins.example.txt 复制成 data\plugins.txt，去掉想启用插件前面的 #，
   下次启动自动生效。也可以在 Web 界面「设置 -> 插件管理」里直接开关。
6) 想安装第三方插件？
   包里已自带 pnpm，直接在 Web 界面「设置 -> 插件管理」里安装即可，
   不需要在这台电脑上另外装。随包自带的实验插件也能在那里开关。
7) 需要执行 git 命令怎么办？
   本包不再附带 Git。请在这台电脑安装系统 Git，并确保 git 在 PATH 中；
   没有 Git 也能正常启动和使用 Harness，只是 Agent 执行 git 命令时会报错。


维护（诊断 / 备份 / 恢复 / 更新）
--------------------------------
双击 Windows-Maintain.bat，按菜单选择：
   1 离线诊断     2 备份            3 查看 / 恢复备份
   4 从新版目录更新  5 回退中断操作    6 清理运行记录


请不要
------
- 不要在两台电脑上同时写同一个 U 盘目录。
- 不要直接运行 platforms 目录里的 node.exe 或 dsh 脚本。
- 不要在运行中拔盘：先退出黑窗口，再使用“安全弹出”。


出问题时
--------
保留黑窗口里的原始文字（或截图），连同你刚才的操作步骤一起反馈。
